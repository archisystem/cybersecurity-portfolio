# 🌐 Networking Basics

Практические лабораторные работы по основам компьютерных сетей.

В этом разделе собраны материалы, связанные с изучением сетевого взаимодействия, анализом пакетов и базовыми сетевыми технологиями.

## 📚 Topics

* ARP
* IP addressing
* Multicast
* Packet capture
* Basic network analysis
* GNS3

## 🔎 Practical Work

### ARP

Изучение работы протокола **ARP** и взаимодействия устройств внутри локальной сети.

Материалы:

* `src/arp`
* `src/arp.pcap`
* `src/ai-logs/arp.md`

### IP

Практическая работа с IP-сетями и сетевыми параметрами.

Материал:

* `src/ip-1`

### Multicast

Изучение multicast-трафика и анализ захваченных пакетов.

Материалы:

* `src/multicast`
* `src/multicast.pcap`

### GNS3

Практическая работа с сетевой лабораторией в **GNS3**.

Файл лаборатории:

* `src/gns3.gns3`
