Отчёт по исследованию SMB-трафика
1. Общее описание происходящего в дампе

В дампе наблюдается обмен данными между клиентом 192.168.100.168 и сервером 10.160.67.244 по протоколу SMB.

Сначала клиент и сервер согласовывают версию SMB. Затем происходит установка SMB-сессии и аутентификация пользователя с помощью NTLM.
После успешного установления соединения начинается дальнейший обмен SMB-трафиком. В последующих пакетах данные SMB передаются в зашифрованном виде.

2. Версия SMB-диалекта

В пакете Negotiate Protocol Response в поле Dialect указано:

SMB 3.1.1 (0x0311)

Таким образом, в соединении используется SMB-диалект SMB 3.1.1.

3. Session ID установленного соединения

В пакете Session Setup Response найден идентификатор SMB-сессии:

0x0000281cac000069

Этот идентификатор используется для обозначения установленной SMB-сессии.

4. Учетная запись

В информации о сессии указана учетная запись:

administrator

Таким образом, для подключения использовалась учетная запись administrator.

5. MAC-адреса действующих сторон

В заголовке Ethernet первого SMB-пакета указаны следующие MAC-адреса:

Клиент:
52:55:00:d1:44:45

Сервер:
52:54:00:07:03:2d

Соответствие адресов:

Устройство	IP-адрес	MAC-адрес
Клиент	192.168.100.168	52:55:00:d1:44:45
Сервер	10.160.67.244	52:54:00:07:03:2d
Итог

В исследованном дампе клиент 192.168.100.168 устанавливает SMB-соединение с сервером 10.160.67.244. 
В ходе установки соединения используется SMB 3.1.1, создаётся SMB-сессия с идентификатором 0x0000281cac000069,
а для аутентификации используется учетная запись administrator.
