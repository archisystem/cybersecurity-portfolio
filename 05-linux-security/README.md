# 🐧 Linux Security

Практические лабораторные работы по администрированию и базовой защите Linux-систем.

## 📚 Topics

- Bash scripting
- System information gathering
- Processes and open ports
- Users and groups
- File permissions
- sudo
- Apache
- Cron
- Logwatch
- Postfix
- SSH
- Public-key authentication
- iptables

## 🔎 Practical Work

### Task 1 — System Information

Сбор информации о Linux-системе с помощью Bash-скрипта.

Материал:

- `src/Task-1/get_all_info.sh`

### Task 2 — Linux Users & Permissions

Создание пользователей и групп, настройка прав доступа и sudo.

Материал:

- `src/Task-2/setup_linux.sh`

### Task 3 — Cron & Postfix

Настройка автоматизированных задач и базовая конфигурация почтовой службы.

Материалы:

- `src/Task-3/cron.txt`
- `src/Task-3/main.cf`

### Task 4 — SSH & Firewall

Практика настройки SSH и анализа правил firewall.

Материалы:

- `src/Task-4/sshd_config`
- `src/Task-4/iptables.txt`

## 🛠️ Tools

Linux, Bash, SSH, Apache, Postfix, Cron, iptables.

## 🎯 Goal

Получить практический опыт администрирования Linux и познакомиться с базовыми механизмами защиты системы.
