# 🌐 Networking Protocols

Практические лабораторные работы по основным сетевым протоколам.

В этом разделе собраны практические материалы по работе сетевых служб, передаче данных и анализу сетевого трафика.

## 📚 Topics

* DHCP
* DNS
* NTP
* SSH
* Static routing
* PCAP analysis

## 🔎 Practical Work

### DHCP

Изучение работы DHCP и процесса автоматической настройки сетевых параметров.

Материалы:

* `src/dhcp`
* `src/dhcp.pcap`

### DNS

Практическая работа с разрешением доменных имён и анализом DNS-трафика.

Материалы:

* `src/dns`
* `src/dns.pcap`
* `src/ai-logs/dns.md`

### NTP

Изучение синхронизации времени между сетевыми устройствами и анализ NTP-пакетов.

Материалы:

* `src/ntp`
* `src/ntp.pcap`

### SSH

Практическая работа с протоколом безопасного удалённого доступа.

Материалы:

* `src/ssh.pcap`
* `src/ai-logs/ssh.md`

### Static Routing

Практика настройки статической маршрутизации в сетевой лаборатории.

Материалы:

* `src/static.pcap`
* `src/static-routing.gns3project`
